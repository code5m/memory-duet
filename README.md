# 记忆搭子 Memory Duet

把“我怎么记住”变成可以分享、试记、收藏和比较的学习作品。

## 项目定位

记忆搭子是一款面向学习场景的 AI 记忆共创原型。用户先按学习内容分类，再选择画面、故事、联想、分镜、组块、口诀等记忆方法。系统根据文字描述生成专门的记忆图提示词，接入图片生成服务后，用户可以把自己的照片或 AI 生成图片发布成记忆任务。

用户可以发布“速记漂流瓶”，邀请其他人看图投递口诀、故事或联想。发布者通过点赞、收藏、独立回忆结果和精选回信，判断哪种记法更容易被记住。

## 当前原型

- 分类学习入口
- 英语、语文、数字记忆示例
- 画面记忆、故事记忆、联想记忆、分镜记忆、组块记忆
- 文字描述生成专用记忆图片提示词
- 学习卡遮住线索后的独立回忆
- 上传照片发布学习任务
- 速记交友和口诀漂流瓶
- 个人空间中的“记忆宫殿 · 待开发”
- 日日新图片生成服务的服务端适配层

## 本地运行

```bash
python3 server.py
```

打开 `http://127.0.0.1:8765`。

## 图片生成配置

密钥只放在服务端环境变量中，前端不会读取密钥。

```bash
export RIRIXIN_API_KEY='你的密钥'
export RIRIXIN_IMAGE_ENDPOINT='图片生成接口地址'
python3 server.py
```

日日新接口的字段如果不同，只需要调整 `server.py` 中的适配层。
