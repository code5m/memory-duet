# 记忆搭子 · Memory Duet

> 学习可以有自己的方法；记忆也可以和搭子一起创造。
>
> **2026-11-23 · V3 功能分支**：30 个基础分类维度与自由组合、26 个专题的章节学习、122 张示例学习卡、游客交友，以及两类漂流瓶与多人共学练习室。

## 如何体验

### 本地网页 + 共享社区

无需下载第三方依赖，Python 3.9+：

```bash
python3 server.py
```

打开 <http://127.0.0.1:8765/>。使用两种浏览器或两台能访问同一个服务地址的设备，输入**任意非空昵称**，就能作为不同游客发瓶、回信、关注、私信和共学。无需邮箱、手机号或密码。

**游客昵称不是身份验证。** 相同昵称允许重复；创建游客时服务端发放独立随机会话令牌，浏览器本地保存令牌，以便保留发帖管理权限。清除浏览器数据后不能凭昵称找回，勿将游客身份用作可靠账户体系。

### 访问和使用

- **分类学习**：30 个基础维度可随时切换；不同维度 AND、同一维度多值 OR；支持搜索、排序、收藏和为原创卡自建维度。
- **专题图书馆**：26 专题，122 张原创入门示例学习卡；每个专题有「先认识 / 学会分辨 / 独立回忆」章节。
- **太难记漂流瓶**：把知识难点抛到海岸，请其他游客提供画面、故事、口诀等记法；瓶主可精选回信。
- **记忆秘诀瓶**：分享可复现的记忆方法和验证步骤，供其他游客尝试、评论和收藏。
- **交友**：免密码昵称进入、兴趣推荐、关注、互相关注私信、随机接瓶、点赞、收藏、屏蔽、举报和贡献榜。
- **共学练习室**：最多 8 位游客围绕一道题独立回忆，由服务端核对参考答案；无提示正确、提示后正确与错误分别标记。
- **结伴挑战**：参与固定记忆挑战，完成状态为参与者自报，不能当作真实的记忆能力成绩。
- **创作**：原创学习卡、个人笔记、图片/文字助记线索与复习建议。学习数据默认保存在本浏览器。

## 多端支持

| 客户端 | 状态 |
| --- | --- |
| PC 浏览器 | 响应式三栏学习工作台 |
| 平板浏览器 | 自适应学习工作台 |
| iOS / Android 移动浏览器 | 底部导航与单列卡片，可通过 HTTPS 部署为 PWA |
| 微信小程序 | 原生 WXML/WXSS 适配代码，含分类组合、专题、交友、双瓶、共学 |
| 在线多人共享 | SQLite 后端，需要部署同一个可访问的服务端地址 |

微信开发者工具导入 `miniapp/`，将 `miniapp/project.config.json` 的 `touristappid` 更换成自己的 AppID。将 `miniapp/config.js` 的 `baseUrl` 设置为部署后的 **HTTPS** 域名，并在微信公众平台加入 request 合法域名。**本仓库不能直接替你完成小程序注册、审核、正式域名和真机上线。**

## 测试

需要 Node.js 20+ 和 Python 3.9+：

```bash
node tests/catalog.test.js
node tests/extended_catalog.test.js
python -m unittest discover -s tests -p 'test_*.py' -v
```

静态 JS 语法：`node --check web/app.js && node --check web/social.js`。

质量门禁位于 `.github/workflows/quality.yml`，覆盖学习数据、多维筛选、试记规则，以及游客/双瓶/回信/点赞/私信/共学/举报 HTTP 集成测试。

## 安全与局限

- 不会要求密码，但昵称可被别人重复。服务端会话令牌仅用作匿名游客的写操作权限凭据。
- 内容持久存储在部署服务器的 `data/community.sqlite3`；浏览器上的收藏与独立练习仍保存在本设备，不自动跨端同步。
- 发瓶、回信和共学内容为用户公开提供，任何人都可能提交错误或不当内容。服务端有请求大小、频率限制、举报临时隐藏、屏蔽和管理员审核接口，但**不等于已有人工审核团队**。
- 共学室答案可被服务端核对，但“是否查看提示”由用户申报；挑战打卡为自报，不应当作受监督考试或真实长期保持证明。
- 图片生成目前有服务端代理和提示词生成入口，但尚未完成图像服务真实授权、计费与端到端效果验收。
- 本仓库只包含源代码；没有替用户购买域名、部署线上服务、微信发布审核或完成各型号手机真机视觉验收。
