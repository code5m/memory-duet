# 测试与验收

运行：`python3 server.py`，浏览 http://127.0.0.1:8765/。
- `node tests/catalog.test.js`：内容数量、引用完整性、30 维度筛选、数字前导零与复习状态。
- 访问根路径以及 `/styles.css`、`/app.js`、`/data/catalog.js` 并检查 MIME。
- 逐项试用专题 → 学习卡 → 遮住线索 → 无提示 / 有提示答题 → 独立评分。
- 检查搜索、30 维切换、收藏、原创内容、导出、漂流瓶文件交换、旧存储迁移。
- 在 320、375、430、768、1024、1440、1920 CSS 像素下检查布局与安全区。
- 使用微信开发者工具导入 `miniapp/`，替换正式 AppID，再执行真机和审核验收。

限制：没有在线账户、跨端同步、实时社区、小程序真机通过证明。旧版答题记录没有提示和时间语义，不能冒称新的独立练习成功。
