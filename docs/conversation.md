# 对话形成的公开决策摘要

## 起点

项目从“把自适应形象记忆教练做成可参赛原型”开始。早期方案强调单人答题和错误纠正，后来发现更适合参赛的核心是让用户自己创作记忆材料，并由其他人试记和评价。

## 主要决策

1. 软件按学习内容分类，而不是只按记忆方法分类。
2. 画面、故事、联想、分镜、组块和口诀都作为可切换的记忆作品类型。
3. 用户可以上传自己的照片，也可以由系统根据文字描述生成专用图片提示词。
4. 图片必须服务于记忆任务，提示词要明确动作、顺序、角色和答案的对应关系。
5. “速记交友”采用漂流瓶任务。瓶主发布照片和任务，其他人投递口诀，瓶主选择最佳版本。
6. 记忆宫殿放在个人空间，并标记为待开发。
7. 当前先做能现场体验的原型，再接入真实生图服务、多人同步和持久化数据。
