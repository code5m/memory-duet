# 产品想法

## 一句话

让每个人都能用自己的照片、故事和联想制作记忆方法，再由其他学习者亲自试记，找到真正容易记住的版本。

## 核心闭环

```text
学习任务 → 选择记忆法 → 文字描述 → 专用生图提示词 → 图片或故事作品
    ↓                                                ↑
独立回忆 ← 遮住线索 ← 试记 ← 社区点赞、收藏、留言和口诀投稿
```

## 学习分类

- 英语，读音、拼写、词义和使用
- 语文，字形、古诗、课文和阅读理解
- 数学，公式、步骤和变式应用
- 科学，概念、因果关系和过程
- 专业知识，术语、流程和表格
- 生活技能，物品、步骤和注意事项
- 记忆训练，数字、顺序、组块和竞赛方法

## 记忆方法

画面记忆把知识放进清晰场景。故事记忆把多个知识点串成有动作和结果的情节。联想记忆把陌生知识连接到熟悉动作、声音或形状。分镜记忆适合顺序和课文。组块记忆适合数字和零散事实。口诀、手指、身体桩、PAO 和记忆宫殿逐步加入。

记忆宫殿放在个人空间中，当前标注为“待开发”，因为它需要用户保存熟悉路线、地点桩和个人复习记录。

## 冲刺参赛演示

1. 评委选择“英语词义”。
2. 输入一个容易混淆的词或上传自己的照片。
3. 系统根据记忆技能判断适合的主方法，生成专用图片提示词。
4. 评委选择画面版、故事版或联想版。
5. 收起线索，完成一道新题。
6. 另一位评委发布自己的口诀，瓶主选择最佳版本。

作品的重点是让评委亲自感受到“生成记忆材料”和“验证是否记住”是连在一起的。
