# 技术结构

## 当前原型

```text
浏览器
  └── 分类学习 / 学习卡 / 发布任务 / 漂流瓶
        ├── 本地状态
        ├── 记忆提示词生成
        └── POST /api/generate-image
                    └── 日日新适配层
```

当前网页原型可以独立展示核心交互。`server.py` 提供静态文件和服务端图片生成代理。Key 只读取环境变量，不进入 HTML 和浏览器脚本。

## 后续模块

- 记忆技能路由器，按学习目标选择画面、故事、联想或其他方法
- 教案校验，检查答案、顺序、数字前导零、提示泄题和独立测题
- 图片作品版本和生成记录
- 点赞、收藏、独立回忆和延迟复测统计
- 漂流瓶任务、回信、精选和轻量搭子关系
- 个人空间和记忆宫殿

## 隐私边界

公开仓库不包含任何 Key、Cookie、个人照片、真实学习档案或内部聊天原文。公开对话文件只保留产品决策摘要。
