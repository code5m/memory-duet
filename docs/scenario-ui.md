# 场景化交互（V4）

| 场景 | 首页 | 导航与操作 | 主题 |
|---|---|---|---|
| 专注学习 | 专题、课程、练习、复习 | 分类、专题、复习、原创卡、个人学习记录 | 紫色；练习时收起辅助内容 |
| 记忆交友 | 记忆海岸、两类瓶子 | 广场、太难记、秘诀、找搭子、共学、挑战、私信、收藏、游客名片 | 青绿色；社交操作优先 |
| 自由探索 | 两个场景入口 + 学习推荐 | 学习与交友混合导航 | 双场景卡片 |

场景偏好存储在当前客户端。网页切回学习可恢复当前页面和未提交答题文本（本次页面会话）；小程序切回学习首页可继续最近学习卡的新一轮练习。已保存的学习记录和游客令牌不受模式切换影响。交友到学习的秘诀草稿不会自动创建正确答案。学习到交友的难题草稿不会复制参考答案、作答记录或笔记，发布需要用户点击确认。小程序的 WXML 与平台组件兼容性、真实合法域名、真机体验仍需微信开发者工具验收。
