# 42 种记忆技巧的分类与使用规则

> 这是教学工具目录，不代表 42 种互相独立或被同等强度实验验证的科学方法。编码技巧能制造线索，**无提示提取和反馈**才检测是否真正记住。先选择一项主方法；不要逐条全用。

## 视觉与画面（6）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| V01 | 实物图片配对 | 具体名词、器官、动植物：看准确图片→说名称→盖图回忆 | 图片必须符合真实知识；只记颜色可能干扰 |
| V02 | 字形变画 | 生字部件、易混字：把部分字形和具体形状对应→再还原标准笔画 | 不把艺术变形当正确书写；英文优先真实拼读 |
| V03 | 夸张动态画面 | 两个零散词：构造一个强烈但简单的动作场景连接它们 | 场景不能变成错误事实；避免儿童不适 |
| V04 | 分镜漫画 | 故事、过程：3–6 格分别画原因、事件、结果 | 保留事件关系，不为热闹虚构人物事实 |
| V05 | 自主快速绘画 | 具体词、概念节点：学习者画 10–30 秒草图后复述 | 绘画美术水平不是评价目标 |
| V06 | 颜色层级编码 | 对照项、分类：仅给少数稳定类别固定颜色 | 不单凭颜色承载核心含义，兼用文字标签 |

## 声音、拼音、语言（6）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| S01 | 汉语拼音首字母 | 连续短清单：取词组拼音首字母形成易回想提示 | 字母重复时需一一核对，不可遗漏原项 |
| S02 | 汉字拼音与声调分解 | 识读字音：拼音声母、韵母、声调分段练习再合读 | 不以自造谐音代替标准声调；区分拼音与字形 |
| S03 | 英语真实拼读 | 单词发音与拼写：识别音素、常见字母组合与例外，再读写 | 不能把不规则拼写硬解释成规则 |
| S04 | 谐音检索线索 | 难记术语/外语词：用熟悉声音建立一次性提取线索 | 中文谐音≠标准外语发音；同时给正确发音与拼写 |
| S05 | 押韵口诀 | 有规律的序列、规则：压缩成押韵短句，再展开原文 | 易丢定义和适用条件，必须能还原原句 |
| S06 | 节奏、分音节与拍手 | 长词、韵文：按**正确**音节和重音进行节奏练习 | 不可仅凭拼写任意切音节；拍手是辅助 |

## 联想与故事（5）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| A01 | 语义联想 | 新知识挂接熟悉概念：说出一个真实关联并解释 | 避免似是而非的错误类比 |
| A02 | 奇特联想 | 两个关联弱的项目：让 A 与 B 发生夸张动作 | 仅作为提示，不当作事实陈述 |
| A03 | 故事串联 | 无联系的 3–8 项：将相邻项写成可复述情节 | 顺序和项目容易漏，事后逐项核对 |
| A04 | 关键词法 | 外语词义：找到音近线索→联接语义画面→还原原词 | 不能代替真实语音训练；慎用于小学生首学拼写 |
| A05 | 类比桥接 | 抽象概念：用一个熟悉情境解释共性及不相似点 | 必须明确类比在哪些地方失效 |

## 空间、定位与记忆宫殿（5）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| L01 | 地点法/记忆宫殿 | 有序大量条目：固定熟悉地点、单向路线、一处一项 | 首先走通路线，再放知识；有启动成本 |
| L02 | 路线定桩 | 家到学校/房间到门口：每个地点放一项编码 | 路线方向和桩位不可随意切换 |
| L03 | 房间物件定位 | 以熟悉房间 5–10 个家具作桩位 | 一次只用固定顺序，勿临时增减家具 |
| L04 | 虚拟场景宫殿 | 喜欢游戏/画面者：先建立稳定可复现的场景地图 | 场景不稳定者不如真实熟悉路线可靠 |
| L05 | 编号桩/格点 | 用 1–10 稳定序号和固定图像对应知识 | 编码本身需要先熟悉，不宜频繁更换 |

## 手指、身体、动作（5）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| B01 | 五指记忆 | 五件事：固定拇指→食指→中指→无名指→小指映射 | 桩位表本次课程必须稳定；不主张五指通吃 |
| B02 | 指关节定位 | 8–12 个有序项目：预先规定每只手的关节行进顺序 | 必须明示左右手、关节顺序，避免混淆 |
| B03 | 身体桩 | 头、肩、手、腹、腿、脚等位置放对应图像 | 避免不适的触碰内容；作为定位提示非医学记忆 |
| B04 | 手势与动作象征 | 学结构、方向、规则：把手势对应关键关系 | 让手势强化概念，不能替代定义及验证 |
| B05 | 真实动作执行 | 实操流程、动作词：看一次→亲自执行→独立完成 | 对不安全的动作只做模拟，不鼓励危险操作 |

## 竞技/超级记忆编码（6）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| C01 | 数字形状法 | 少数数字：用稳定形状对应，例如 0→圆环 | 数字需要逐位还原核对；小数字优先组块 |
| C02 | Major System 数字辅音法 | 大量数字：数字→辅音→词→形象 | 映射需一致，语言版本不同不能混用 |
| C03 | Dominic System | 长数字：用稳定的人物动作编码两位数字 | 记忆成本较高，先熟悉映射再投入使用 |
| C04 | 00–99 双位数字图像 | 竞技数字：将每组两位映射成固定图像 | 需事先训练 100 个映射，无法当场自动精通 |
| C05 | PAO 人物—动作—物品 | 扑克和长数字：使用固定角色、动作、物品组合 | 先定义一致的编码表，避免临时编码歧义 |
| C06 | 扑克花色点数编码 | 扑克记忆：先稳定编码→场景化→定位→提取 | 竞赛专项训练，不直接等于普通学科学习 |

## 理解与结构（5）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| U01 | 组块与结构化分组 | 有意义的内容按真实结构分组；随机数字可按固定长度分块核对 | 有意义的组块要能解释；随机分块不是知识因果，也不能自动增加理解 |
| U02 | 思维导图/概念图 | 模块关系：画主题→分支→具体联系并口述 | 画图不是最终目的，须无图还原关系 |
| U03 | 因果链 | 科学、历史、故事：写“原因→过程→结果→影响” | 因果须有来源依据，不虚构必要性 |
| U04 | 实物/图解推导 | 数学、物理：用物体或可检验图解导出规则 | 严格检查单位、边界和例外 |
| U05 | 比较与对照 | 易混概念：对比共同点、区分点、反例 | 不能只看相似，还需独立判断题 |

## 提取与巩固（4，默认过程而非编码）

| ID | 技巧 | 适用任务 / 30 秒做法 | 边界 |
|---|---|---|---|
| R01 | 主动回忆 | 遮住提示，自行说、写、画或完成目标 | 必须记录是否独立成功，提示后成功不能算同一水平 |
| R02 | 间隔复习 | 从当天稍后、次日等不同时间重复无提示检索 | 间隔随难度调整，不保证特定天数最优 |
| R03 | 交错练习 | 多类数学题或易混概念混合判断该用哪种方法 | 初学全新内容前可先集中掌握基础 |
| R04 | 错误定位与反馈 | 将错误归因于顺序、音、字形、理解、迁移等，再改方法 | 纠正答案后需重新无提示验证，不只“看懂” |

## 注意：语言细分与方法选择（v3）

- 语言题应先确定目标是正确读音、准确拼写、词义理解、词语运用、汉字字形或阅读理解，再决定 S03/S02/A01/U05/V02/U02；不能见到“英语”就统一 S03。
- 抽象概念的 `causal` 类型优先 U03（须确有证据支持因果）；分类用 U05，空间/数量可 U04。
- 方法目录不是必须全部被路由脚本自动选中的选项；S04、L04、C02 等需学习者有具体需求、正确素材及必要的前提时才手动选用。

## 选择优先级（务必遵守）

1. **理解优先**：U04/U03/U05 > 口诀/谐音。需要解题的内容优先掌握原理。
2. **准确优先**：S03（英语发音）和 S02（拼音声调）高于 S04 临时谐音。
3. **低认知负担优先**：短清单 B01、规律明显 U01；长且需排序才考虑 L01。
4. **小目标优先**：初学每回合 3–6 个项目或一个核心概念；视学者表现调整。
5. **测量优先**：始终进行 R01 与 R04；需要长期记忆时加入 R02；掌握后适当 R03。
