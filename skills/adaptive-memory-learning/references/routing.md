# 动态选法决策树 v5（离线、可审计）

这是一套**可复核的教学启发式**，不是诊断模型、学习风格测验或科学验证的预测分数。对缺失的知识、教材原文、位置数量、发音和学习表现，不得伪造。

## 1. 判断学习瓶颈，而非先选花哨方法

将目标与任务拆开：

- **目标**：理解 `understand`、准确回忆 `exact_recall`、保持顺序 `ordered_recall`、长期保持 `long_term`、灵活应用 `transfer`、竞赛 `competition`。
- **类型**：`object` 实物、`language` 文字与读写、`concept` 概念、`ordered` 顺序、`digits` 数字串、`procedure` 动作流程、`narrative` 叙事、`scattered` 零散知识。
- **语言专项目标** `language_focus`：`unspecified/pronunciation/spelling/meaning/usage/character_form/reading_comprehension`。若目标 `understand/transfer` 且专项未说明，分别优先词义/运用，不默认拼读。
- **瓶颈（可多个）**：不懂、误读、拼错、顺序错、看提示才会、线索能记却解码失败、隔天忘记、记忆负担过重。
- **学习者**：只使用用户确认的年龄、已有知识、偏好与辅助条件。`unknown` 不代表零基础，也不能据此贴学习风格标签。

先找可推理的结构；真正无规律的项目才考虑编码。课堂中最多用一个主要方法和一个互补辅助方法；`R01/R02/R04` 属于默认流程。

## 2. 核心选型表

| 情境 | 首选 | 何时加辅法 | 何时不要这样选 |
|---|---|---|---|
| 实物名词、具体对象 | V01 准确图片；不使用图像时 A01 语义关联 | 通常不加 | 一两个简单词不强制绘画+故事 |
| 英语发音或拼写 | S03 标准语音与拼读 | 具体词义实际可看图时 V01 | 拼读不能替代词义、语用和阅读理解 |
| 英语、汉语词义 | A01 语义联想 | 可对应具体实物时 V01 | 不能只会背读音却不懂意思 |
| 词语运用 | U05 正例反例 | A01 真实语境联系 | 要有独立造句、换语境判断 |
| 汉字字形 | V02 字形辅助或 U01 部件分析 | 无视觉时采用文字结构与规范书写 | 不把漫画画法当标准笔画 |
| 其他语言初学 | 先查标准音/字形；暂以 U01 分块 | 证据充分再加方法 | 未核验语言时自动编中文谐音 |
| 数学空间、数量、公式 | U04 实物图解与推导 | 动作真正有用时 B04；迁移时 U05 | 不能只背答案，不区分面积与周长 |
| 有依据的因果概念 | U03 因果分析 | V04 真实过程分镜 | 把时间先后冒充因果 |
| 分类与易混概念 | U05 比较/反例 | 图表帮助辨别时 U02 | 只背术语不练判断 |
| 1–2 项无逻辑顺序 | U01 简单组合和独立提取 | 通常不加 | 复杂宫殿 |
| 3–5 项严格有序 | B01 固定五指 | 需要时 V03 | 位置不够还强行使用五指 |
| 恰好 6 项 | B03 六个固定身体位置 | 通常不加 | 六项塞入五指 |
| 7+ 项严格有序，已有路线 | L01，但必须确认**可用桩位 ≥ 所有项目数** | 一般不加 | 只知道“有宫殿”却不知桩位数量 |
| 7+ 项严格有序，无稳定路线 | 7–8 可 A03 短故事；更长 U01 分组 | 小组内可用 A03 | 每次新造大宫殿，无定位容量 |
| 有逻辑的顺序 | U01 层级与步骤关系；明确因果才 U03 | U02 或 V04 | 将逻辑次序假装成因果 |
| 实际动作流程 | B05 真实或安全模拟 | 合适时 U04 流程图 | 肢体活动不可行时强迫实操 |
| 叙事、历史、阅读 | V04 时间线与分镜，或 U03 | 真实因果链 | 加入不存在的事件当史实 |
| 4–8 位简单数字 | U01 分组；可选 C01 | 数字形象真有帮助时 | 为 4 位数建 100 个编码 |
| 10+ 位竞技数字且已有稳定 PAO | C05，并依6位 PAO 场景分组 | 仅在桩位足够时 L01 | 编码或桩位不足，或避免视觉想象时强推 PAO |

> 启发式长度阈值不是普遍最佳长度。使用者已熟悉的路线/编码，以及任务实际难度可改变选择；不要把规则阈值当科学定律。

## 3. 容量与先决条件

1. **五指**：固定拇指→食指→中指→无名指→小指，一轮最多 5 个不同桩位。六项改为六个身体桩（仅在学习者可接受时）或组块。
2. **身体桩**：若选 B03，明确且确认六个具体位置；不使用未经同意的触碰。六只是默认演示，不表示人体只能做六桩。
3. **宫殿**：仅 `has_palace=true` 不足以证明可用；还需知道 `loci_count` 是否大于等于要记忆的项目数，否则先分组、训练路线或选简单方法。
4. **PAO**：两位数字对应一个固定编码。每三个两位数构成六位的 `人物-动作-物品` 场景；16 位数字示例产生 **6+6+4**，尾部四位为人物+动作。尾部单个数字须使用固定的单数字编码，**不得偷偷补零或冒充一个完整二位数**。检查码表中同一角色的形象能否唯一反解数字；用于正式竞技训练时还应确认已熟练掌握完整码表，教学示范局部码表不等于掌握。
5. **前导零**：保留 `03`、`0051` 等文本位数，记录为**字符串**，不得先转整数再生成训练题。
6. **非视觉或动作不方便**：不要推断能力缺陷；改语言解释、语义组块、实物、图示或可接受的替代活动，不要求闭眼想象或动作表演。
7. **读音与教材**：需要特定版本、特定口音时查证，不编造原文或造假标准发音。谐音、拼音辅助必须标识为“联想线索（非标准读音）”。

## 4. 错误反馈直接改变策略

| `observed_error` | 应该怎么改 |
|---|---|
| `spelling` / `pronunciation` | 回标准字形、音素或语音；停用会误导的谐音 |
| `order` | 检查桩位数量、路线、项目顺序；无法满足容量时分组 |
| `understanding` / `application` | 回到图解、例证、对照和迁移，不再叠故事 |
| `cue_only` | 由完整提示→少量提示→无提示，独立成功才能算掌握 |
| `mapping` | 固定线索⇄正确答案的双向解码；简化画面 |
| `delayed` | 原编码可以暂时不变，补有反馈的间隔检索 |
| `overload` | 本轮减半目标数量，取消辅助方法；允许休息 |

只根据**实际作答**标记「独立正确、提示后正确、错误、未测」；不以点击次数、画面印象或系统主观感受推断掌握。

## 5. 课程切分与时间

默认 5 分钟：45秒理解→90秒编码→60秒无提示回忆→60秒反馈→45秒迁移或再测。该时长仅是课堂结构，不是学习效果保证。

当用户给出更多任务时：优先分批，单次教学数量参考小学低年级3项、中年级4项、初中以上6项；抽象概念一次1个；动作流程一次最多3步；竞技已熟悉 PAO 可分每次12位。特殊情况按学习效果调整，**不能保证这些默认数量对所有学习者最优**。

如果用户明确定制时长，等比例调整各环节；短于3分钟提醒缩减内容。短时间项目可不设迁移题（如无意义的随机卡牌），改为顺序/随机回忆。

## 6. 可选自动路由脚本

运行 `scripts/memory_router.py` 可生成解释性建议，**不能**自动分析课文、执行真实测验、生成图片或预测记忆率。输入字段：

| 字段 | 类型、意义 |
|---|---|
| `content_type` | 必需，八类之一 |
| `item_count` | 正整数，数字类型表示数字**位数**，其他表示知识条目数 |
| `goal` | 目标枚举，默认 `exact_recall` |
| `language` | `zh/en/other`，仅对语言类路由关键 |
| `age_band` | `unspecified/early_primary/upper_primary/secondary/adult` |
| `prior_knowledge` | `unknown/new/familiar/trained_coding` |
| `logical_sequence` / `sequence_kind` | 布尔或 `unspecified/logical/causal/procedural`；仅因果场景使用 U03 |
| `has_palace` + `loci_count` | 是否已经有熟悉路线和可用桩位数量，不得省略容量判断 |
| `coding_trained` | 是否已熟悉编码 |
| `concept_kind` | `unspecified/spatial_quantity/definition/classification/causal` |
| `concrete_referent` | 对语言词条是否有可对应的具体物体 |
| `physical_cues_allowed` / `visual_cues_allowed` | 是否适宜动作或视觉提示，默认 true，可设 false |
| `observed_error` | 单个已观察错误（兼容 v2） |
| `observed_errors` | 可选错误列表，最多12项；与单个错误合并去重 |
| `observed_outcome` | `unanswered/correct_unassisted/correct_with_cue/incorrect`，由调用者提供，不能据此编造测试 |
| `language_focus` | 仅语言类，`unspecified/pronunciation/spelling/meaning/usage/character_form/reading_comprehension` |
| `material_complexity` | `unspecified/simple/dense`；标记密集内容时缩小单批量 |
| `lesson_minutes` | 1–60 分钟，默认5 |

**注意**：如果一条内容同时含多种知识，先分出子任务各自选法。`observed_errors` 的优先顺序是读音→拼写→理解→应用→顺序→映射→提示依赖→延迟→过载；**过载降载及延迟复测即使不是首要错误也要生效**。`observed_outcome` 为输入的自报结果，不是程序测得的事实；正确但曾延迟遗忘时，仍优先缩短复测间隔。

使用 `scripts/validate_lesson.py` 对外部已生成的教案做第二道门禁：检查目标与线索映射、位置路线和容量、真正的 PAO 码表、前导零与尾段、每个目标的独立测题覆盖及显式泄题。口头读音题允许显示目标单词；听写题不能显示待拼词。

跨轮次复习可调用 `scripts/review_planner.py`（示例 `examples/review_sample.json`）：按知识点统计**不同练习轮次**，同轮看提示或答错后改正不计为独立成功；次日、3天、7天、14天只是随表现调整的建议，不是提醒任务或个体预测。详见 [output-schema.md](output-schema.md)。

## 7. v5 校验补强（结构检查≠真实学习成效）

- 选法器负责建议，**教案校验器**再检查内容与测题类型是否匹配。数字准确记忆不能使用发音/词义题冒充成功；有序项目不能用发音测验冒充顺序回忆。
- 可在教案输入中显式声明 `goal=ordered_recall` 或 `goal=transfer`：前者需要顺序题，后者需要各目标的迁移题；未知目标不能自行标为已通过。
- 五指/指关节/身体桩容量检查在数字和文字任务中采用一致规则，位置编码映射不得打乱原始目标顺序。
- `review_planner.py` 可选 `session_date`：同一天两次独立答对，虽是两轮练习，却只是一日的间隔证据。缺日期时不冒称已确认跨日保持。
