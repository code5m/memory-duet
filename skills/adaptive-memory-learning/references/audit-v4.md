# 自适应形象记忆教练 v4.0：第四轮源代码审计与修复报告

## 范围与方法

以 v3.0 的 ZIP 文件和解压源码为基线，先复跑 111 项原有自动化测试，再构造反例验证错误资料是否被错误放行；随后修补、加反向断言及随机异常输入测试，最后对最终打包文件独立解压复测。**脚本验收不是面向真实学生的成效实验。**

## v4 主要功能

1. **PAO编码可逆校验**：要求真实两位数字码表；人物、动作、物品必须对应当前位置的数字对。相同角色的图像不得在两个数字对之间冲突。尾部奇数位必须显式提供独立可逆编码，不能偷偷补零。样例中仅演示当前片段的8组映射，**不声称使用者已有完整00–99稳定码表**。
2. **定位路线完整性**：地点/编号桩需要无重复的 `loci_sequence`、用户确认 `route_familiar_confirmed`；编码顺序和容量必须一致。确认字段是调用者声明，不能证明实际熟悉程度。指关节 B02 需声明左右手关节次序。
3. **测验覆盖与模式**：完整课至少覆盖所有目标/所有数字位；只有认出答案的 recognition 不算无提示回忆；发音题可以展示词形，拼写题不能直接展示待拼单词；当 `language_focus` 存在时每个目标应有匹配测题。
4. **异常输入防护**：覆盖错误类型、重复键、列表/字典等嵌套格式，返回错误而非未捕获异常。加入随机异常形状测试。
5. **基于练习轮次的复习建议**：无授权不持久化记录、不创建提醒。只有跨独立轮次获得的正确答案才累计轮次；同一轮先错误/提示后修正不当作长期独立成功。1/3/7/14天为建议启发式，需根据真实反馈调整。
6. **教学 QA 清单**：新增 8 维教师人工评分及发布阻断条件，保证代码门禁外仍有内容正确性、儿童适龄和教学可实施性审查。

## 版本与兼容性

- 保持技能名 `adaptive-memory-learning`、8大组42项方法编码、现有路由参数不变。路由输出 `engine_version` 升级至 `4.0.0`。
- 原 `validate_lesson()` 返回顶层 `ok/errors/warnings/checked` 保留，但**有意收紧通过标准**。v3 的 PAO 或定位教案若只写解码字符串、未提交原始码表与路线，会在 v4 被拒绝；请补齐 `pao_codebook`、`pao_parts`、`loci_sequence`、`route_familiar_confirmed`、测题完整覆盖等字段。
- 新增 `scripts/review_planner.py`；输入来自用户/家长/老师自愿提供的匿名尝试记录。未实际开展复测时不得自动生成成绩。
- 编码字符串校验器不能证明图片/音频本身的真实性，也不能完全理解自由文本题干的语义泄题；人工教师仍需复核。局部 PAO 码表不代表已能完成竞技记忆。

## 自动化与人工验收边界

- 旧版 111 项均保留并适配预期变更；新增与扩展的 adversarial、容量、目标覆盖、练习轮次及异常输入自动测试，总数以本轮最终运行结果为准。
- 包含 4,000 组随机**合法路由组合**的回归测试，以及 1,000 组随机**畸形教案输入**的无崩溃检验。这两个都是程序不变量测试，**不是学习者样本数**。
- 人工验收清单新增至 72 个场景。清单不等于已逐条实际授课或完成教学效果实验。
- 最终须运行 `scripts/check_skill.py`、全部 `test_*.py`、官方 Skill 格式校验、ZIP 文件完整性检查，并且从 ZIP 解压后重新运行测试。

## 仍然存在的边界

- 无法仅凭用户自行提供的映射断言其符合真实世界事实或学习者确实熟悉；研究证据对不同记忆术的效力不均匀。
- 不能在无图像生成工具的情况下直接创建图片、动画或真人教学视频；不能凭文字提示词声称已生成。
- 自动选择器是可解释的经验规则，不是因人而异的经随机试验验证的推荐模型；不能预测儿童成绩。
- 尚未开展真实学生学习效果、障碍可及性大样本、语音图片质量与跨平台安装的实测。上述验收请在实际工具和授权下另行执行。
