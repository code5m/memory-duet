# 自适应形象记忆教练 v5.0：第五轮源代码逆向审核与优化

## 审核对象与范围

以 v4.0 `/mnt/data/skill.zip` 的解压源码为基线，**先执行原有159项测试**，随后新建反例验证是否错误放行。检查范围包括选法、桩位容量、数字保真、测验目标对齐、无提示考核、复习日期证据、非法JSON输入，以及完整ZIP交付。**未测试真实学生的学习提升，也未实际安装到终端账户。**

## 已确认的误判与修复

| ID | v4反例 | v4结果 | v5处理 |
|---|---|---|---|
| Q01 P0 | 16位数字测试标成“解释词义” | 错误通过 | 数字只接受准确数字/顺序回忆模式 |
| Q02 P0 | 有序列表测试标成“发音/词义” | 错误通过 | 非顺序回忆不能补足清单的无提示测验 |
| Q03 P0 | 8个数字片段塞进五根手指 | 错误通过 | 数字/文字同用五指5桩容量门禁 |
| Q04 P1 | 两位数字原答案写在题干 | 错误通过 | 检查短数字显式泄题；对“第5位”等位置标签做保守豁免 |
| Q05 P1 | 地点编码改变原始目标顺序 | 错误通过 | 定位映射的目标顺序必须和原目标一致 |
| Q06 P1 | 数字使用超过默认6位置的身体桩 | 错误通过 | 超6位置需明确足够且顺序匹配的桩位列表 |
| Q07 P1 | PAO片段携带未知角色字段 | 忽略 | 严格拒绝非 person/action/object/single_digit 字段 |
| Q08 P1 | 路由JSON同一key出现两次、含NaN | 静默接受或不一致 | 与另外两个入口统一：拒绝重复键与非有限数 |
| Q09 P1 | `goal=transfer` 的概念课只背定义 | 没有目标对齐校验 | 新增可选goal校验与迁移题覆盖门禁 |
| Q10 P1 | 同一天做两次独立复习，被用于放大间隔建议 | 未区分日期 | 可选session_date，按不同日期数限制间隔扩展 |

## 保持与兼容

- 技能根目录、文件夹名、42种方法编号和8大类不变；保持 `choose_plan`、`validate_lesson`、`plan_review` 调用形式。
- 路由输出 `engine_version`、校验输出 `schema_version`、复习计划输出 `engine_version` 更新至 `5.0.0`。
- 新字段 `goal`、`session_date` 都是可选输入；没有这些字段的既有样例和测试继续有效。对于以前误放行的结构化教案，新版有意收紧校验。
- 对长久保持目标只警示：必须观察真实延迟回忆，程序不能从教案推断学生成绩。

## 测试边界

- 原有159项自动测试均保留，新增26项（涵盖逆向样例、合法对照及可选日期复测），**当前合计185项**；最终数目以本轮实际测试为准。
- v4原有随机4,000组合法路由与1,000组畸形教案测试仍在回归中，计入上述自动化测试。它们不是学生数量或效果提升百分比。
- 人工验收场景清单扩展为T01–T80（**80项待人工逐项试教**，并不声称全部完成）。
- 程序无法可靠判断自然语言含义是否在题目中暗示答案、生成图像与真实物体是否匹配、教师读音是否标准、儿童是否自愿使用动作；必须人工检查。
- `session_date` 仅来自调用者自报，无法证明实际上哪天做题；若未提供完整日期会标记“未验证真实间隔”。同一日多轮答对只能构成一日的日期证据，不能推断长期保持。
- 整个项目完全离线运行，不生成、收集或永久保存个人儿童学习档案；真实提醒/图片生成需要额外已授权能力。

## 剩余风险与下一步真实验证

1. 选择器属于可解释启发式，不是个性化效果预测引擎；孩子的长期学习效果须通过真实的延迟无提示回忆和迁移测试验证。
2. 自由文本命题仍需人工复核：`answer_ids` 声明覆盖不代表实际题干能有效区分每个知识点。
3. PAO码表的可逆性仅基于提交的字符串，不意味着学习者真的熟悉编码；教材原文、外语发音和图像真实性需单独核实。
4. 核验 Skill 包合法性与本地代码功能，不等于已安装或在所有客户端完成实际 Skill 调用验收。
