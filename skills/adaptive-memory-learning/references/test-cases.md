## 人工验收模板

- [ ] 基础知识正确（包括数字、顺序、音、单位、例外）。
- [ ] 识别主要障碍、合理选主方法，辅助不超过 1 个（R 系列作为基础流程）。
- [ ] 映射有可逆的明确解码说明。
- [ ] 有无提示测验；没有把答案紧贴题目泄露。
- [ ] 有错误纠正、延迟回忆建议；没有虚构分数或提醒创建。
- [ ] 没有超能力暗示、危险内容、捏造研究或图片完成状态。
- [ ] 可为小学四年级英语、数学分别输出准确、有趣、不过载的课程。

## 脚本与自然语言评价边界

`scripts/test_router.py` 只验收规则示例及稳定字段，不会模拟真实学生记忆效果。上述 80 项需要对不同用户问法进行人工审查；通过脚本不等于教学效果已被实证验证。
