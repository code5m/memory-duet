# 记忆微课人工质量评分规程 v5

> 用于教师、家长或人工评审审核生成的课堂，不是机器学习评分，不应凭空代替真实学生成绩。自动化脚本只能验证部分结构。

## 八个维度（每项 0–2 分，总分 16 分）

| 维度 | 0分（阻断/需重做） | 1分（待修） | 2分（满足） |
|---|---|---|---|
| F1 原知识准确性 | 原文/音/数字/公式/单位错误、伪造来源 | 无明显错误但未核实需核实的事实 | 已对照提供材料或可信原始资料 |
| F2 目标与测量对齐 | 例如要会用单词却只让拼写 | 目标拆开但部分测题错位 | 每个目标有对应的测量方式 |
| F3 方法适配与负担 | 简单知识叠加复杂宫殿/谐音、年龄不适宜 | 主法可用但辅法无必要 | 一主法加可选必要辅法，能解释为何选 |
| F4 提示可逆与容量 | 丢项、桩位重复、PAO码表冲突 | 映射完整但部分线索模糊 | 每项都能从线索准确还原原知识 |
| F5 学习者可及性与安全 | 强迫危险动作/触碰/闭眼成像、隐私不当 | 有替代方案但呈现不清楚 | 明确无障碍、非视觉/非动作路径与隐私边界 |
| F6 课堂执行性 | 无步骤或超时承诺、难以落地 | 步骤可做但缺材料/教师话术 | 每段可实际操作，有时间和内容边界 |
| F7 真实独立测验 | 提前泄题、只做识别题、漏测内容 | 已有独立题但反馈规则不清 | 全量目标独立覆盖，按模式判定，答案分离 |
| F8 复测与迭代 | 将提示后正确当掌握，谎称已保存提醒 | 有简单复测但无错因适配 | 按真实错误/独立轮次调整，无成绩夸大 |

**门禁**：F1、F4、F5、F7 任一为 0 时不能发布为“通过审核的课程”；总分 14–16 且上述核心维度均≥1可建议试教；其余须修订。分数是人工审查的一致性工具，不是科学验证的预测分。

## 审核顺序

1. **先核对教材**：与真实用户原文/教学目标对照。不知教材版本、无材料时标记“待核验”，不得编造答案。
2. **检查方法必要性**：如果原知识有可解释的规律，优先理解；简单词不强制三套记忆法。
3. **检查双向映射**：从原知识能生成助记线索，还应能从线索唯一还原原知识。编码只是线索，不是真实的图像/事实证明。
4. **检查撤提示**：阅读、拼写、听写、读音、应用采用匹配的题型。先出题、后核对；不能在未测状态填写独立正确。
5. **检查延迟复测**：把同一课堂中的重复练习与跨轮独立练习分开；安排建议不等于已创建定时任务。
6. **标出局限**：生成的文字画面说明不是实际图片，脚本通过不代表真实学生记得住。

## 三类故障示例

- **看桥的图片→题目：“请拼写 bridge”**：无效听写（提前暴露答案）。正确做法是展示图片或播放正确读音、不在题目区域出现 `bridge`。
- **看打印的 `bridge`→题目：“请读出它”**：合法发音题。若目标是发音，不应因为显示词形而错误地把题目拒绝。
- **数字要求精确复写，却只做解释/发音测试**：不能算达成目标；应有逐位回忆测试，短数字题干也不得显露答案。
- **两次正确都发生在同一轮**：只能认定这一轮观察到独立完成（若曾接受提示或纠错，还不能算该轮全程独立）；不能推断隔天或数日后仍会回忆。

## 真实教学效果评价（另行开展）

最少收集匿名的目标级即时独立正确、提示后正确、次日独立正确和变式正确；必要时设置不使用额外助记法的对照条件。**不得从自动化脚本通过率推断真实学生学习提升百分比。**

## v5 日期与目标对齐复核

教师应查看是否具有完整的学习目标对应题型；“会背/会算/会用/会读”必须分开判断。若提供 `session_date`，在同一天做 3 轮练习不能标记为连续 3 天保持。缺少日期可以提供复测建议，但应注明未验证复习间隔。
